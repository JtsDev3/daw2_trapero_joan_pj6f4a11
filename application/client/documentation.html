Order Management App

Documentation

About the application

Order Management App is the e-commerce tool used by the sales representatives of our European supermarket chain. It lets them register the orders placed by customers and check them later. Every price and amount is calculated on the server, including 21% VAT, and all orders are stored on the server in JSON format.

Products available: Whole Milk 1 L, Free-range Eggs (12 units), Extra Virgin Olive Oil 1 L and Sliced Bread 450 g. Their prices are always loaded from the server.

Getting started

  1. On the Home page, click Login.
  2. Enter your username and password and click Access operations menu. Both fields are required. If the credentials are not valid, an authentication error is shown and you go back to the Home page.
  3. In the Operations menu, choose an operation in the list and click Go.

Operation 1 – Create new order

  1. Enter the order ID (letters, numbers, "-" or "_", up to 20 characters). It must be unique.
  2. Enter the customer's full name, address, email and phone number.
  3. Tick the checkbox of each product the customer wants: this enables its quantity field. Then type the quantity (a whole number from 1 to 999).
  4. Click Submit order. The server calculates the order and saves it. The total amount with VAT included is shown below the form.
  5. If a field is missing, the application tells you which one before sending anything. If the order ID already exists, the order is rejected.

Operation 2 – View orders

Choose one of these options in the View orders menu and click Go:

  • All orders: shows a table with every stored order: order ID, date, customer details, products (quantity × unit price), subtotal, VAT and total.
  • Single order: type an order ID and click Search to see the table with the data of that order. If no order has that ID, an error page is shown.

If the orders file cannot be found or opened (for example, before the first order is created), an error page is shown with buttons to go back to the View orders menu, the Operations menu or the Home page.
